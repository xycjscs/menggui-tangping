## 2026-08-18 v0.1.0 首版完成

### 09:00 立项与调研
- 参考游戏：《猛鬼宿舍》（猛鬼别闹/猛鬼宿舍系列小程序）
  - 玩法：6 名躺平者在宿舍睡觉发育，建造/升级床、门、炮塔，抵御猛鬼一波波进攻；门被打破则被抓走。
- 改编方向：**放置化**（idle game）
  - 去掉手动塔防操作，改为全自动战斗 + 离线收益
  - 保留核心爽点：床位解锁、门等级视觉成长、波次鬼袭紧张感
- 变现设计：激励视频广告 6 个点位 + 底部 banner
  - 金币红包 / 双倍收益1h / 延迟猛鬼10min / 修复大门 / 离线收益翻倍 / **门破复活**（核心变现点）

### 09:20 素材收集（全部 CC0，Kenney）
- `Roguelike RPG Pack` → 地板/墙壁/3种门(单门/双开门/加固门，正好做门等级视觉)/树/木箱/床(15格拼)/金币/灵魂/炮塔/剑图标

- 成品 102KB，全部 CC0 可商用

### 09:50 核心逻辑设计（js/core/gameCore.js，纯 JS 无 wx 依赖）
- **虚拟时钟 s.time**：波次排期全部基于虚拟秒，真实墙钟只用于广告冷却/存档
  - 这是第一个重大设计决策：战斗在任何速度下确定、可测试
- **数值成长曲线**（CURVE 对象集中管理，方便调参）：
  - 床产量 1.55^n > 炮塔 DPS 1.35^n > 鬼血量 1.22^n → 玩家永远追得上
  - 门血量 1.12^n > 鬼伤害 1.05^n → 门领先则永远扛得住
  - 两条曲线约束是防"后期数学必死"的关键
- **战斗模型**：按"实际击杀时间"结算门受击（鬼死即停），避免高波次同帧秒杀
- **失败流程**：门破 → defeated 冻结 → 看广告复活(门回50%,每局限1次,60s冷却) / 接受失败(灵魂x0.3,床等级减半,门炮重置)

### 10:30 数值模拟（tests/simulate.js + tests/tune.js）

  4. 复活广告无冷却 → bot 无限刷

## 2026-08-18 v0.2.0 玩法扩展（英雄/Boss/任务/成就）

### 内容
用户反馈 v0.1.0 后继续"直接开发"，本次扩 4 个系统 + 3 个新广告位：

1. **英雄系统**（灵魂消耗，4 位）：
   - 圣骑士(150灵魂, +4dps×1.25^lv) / 暗影猎手(400灵魂, 减鬼伤8%+2%/级, 上限50%) / 战斗法师(1000灵魂, +12dps×1.18^lv) / 治愈祭司(2500灵魂, 门回血0.5%×1.2^lv)
   - 招募用灵魂，升级用金币，形成"灵魂-金币"双循环
2. **Boss 波**：每 10 波 1 只 Boss（血×10 伤×2.5）+ 减半常规鬼；奖励×5；威胁评估/UI 高亮/Boss 击杀事件
3. **每日任务**：击杀100鬼 / 升级10次 / 赚5000金币，每天重置，看广告领奖（灵魂）
4. **成就**：10 个（首杀/波次/等级/金币/满英雄），灵魂奖励
5. **新广告位 ×3**：daily_bonus(每天1次) / hero_deal(英雄7折券,10min) / task_reward(任务领奖) → 总计 10 个广告位

### 踩坑记录（v0.2 特有）
1. **终局卡点**：3 天模拟出现"第233波起单波耗时 8 小时"——门反击 1.15^n 在 300 级封顶后追不上鬼血 1.22^n 的无限增长。
   - 修复：鬼血量 100 波后软上限（1.22^99 基准 × 1.01^n 放缓），终局变长尾。修复后 3 天打到 1091 波、最长清波 13s。
   - 教训：**等级封顶 + 敌人无限指数增长 = 必出卡点**，模拟时必须看 P90/最长清波，不能只看中位数。
2. **测试断言顺序**：v0.2 任务测试里先刷满进度再测"未完成"，被封顶逻辑掩盖 → 调整为先测未完成再刷满。
3. **变量命名冲突**：测试文件顶层作用域，新增区块变量名（coinBefore）与旧区块冲突 → 加前缀（coinQBefore）。
