## 2026-08-18 v0.1.0 首版完成

### 09:00 立项与调研
- 参考游戏：《猛鬼宿舍》（猛鬼别闹/猛鬼宿舍系列小程序）
  - 玩法：6 名躺平者在宿舍睡觉发育，建造/升级床、门、炮塔，抵御猛鬼一波波进攻；门被打破则被抓走。
- 改编方向：**放置化**（idle game）
  - 去掉手动塔防操作，改为全自动战斗 + 离线收益
  - 保留核心爽点：床位解锁、门等级视觉成长、波次鬼袭紧张感
- 变现设计：激励视频广告 6 个点位 + 底部 banner
  - 金币红包 / 双倍收益1h / 延迟猛鬼10min / 修复大门 / 离线收益翻倍 / **门破复活**（核心变现点）

### 09:50 核心逻辑设计（js/core/gameCore.js，纯 JS 无 wx 依赖）
- **虚拟时钟 s.time**：波次排期全部基于虚拟秒，真实墙钟只用于广告冷却/存档
  - 这是第一个重大设计决策：战斗在任何速度下确定、可测试
- **数值成长曲线**（CURVE 对象集中管理，方便调参）：
  - 床产量 1.55^n > 炮塔 DPS 1.35^n > 鬼血量 1.22^n → 玩家永远追得上
  - 门血量 1.12^n > 鬼伤害 1.05^n → 门领先则永远扛得住
  - 两条曲线约束是防"后期数学必死"的关键
- **战斗模型**：按"实际击杀时间"结算门受击（鬼死即停），避免高波次同帧秒杀
- **失败流程**：门破 → defeated 冻结 → 看广告复活(门回50%,每局限1次,60s冷却) / 接受失败(灵魂x0.3,床等级减半,门炮重置)

### 10:30 数值模拟（tests/simulate.js + tests/tune.js）
- 3 天 86400 秒 × 3 的完整挂机模拟（AI 策略 bot：威胁评估→堆DPS→解锁床→均衡升床）
- 调参过程踩的坑（都记录在 AI_HANDOFF.md）：
  1. 墙钟 tick 导致虚拟时间错乱 → 改虚拟时钟
  2. 鬼伤害增长 > 门血量增长 → 后期必死循环（7817 次门破事故）
  3. 等级上限 100 锁死防御 → 后期软锁
  4. 复活广告无冷却 → bot 无限刷
- 最终节奏：**3天 241 波 / 0 卡死 / 清波中位 6s / P90 359s / 门破 9 次**
- 70/70 单元测试通过
